# 作業手順｜kintone セール価格設定リストの出力と突合

作成: 2026-09-04

エンジニアが実装した kintone の「セール価格設定リスト出力機能」を実際に動かし、
旧システムの出力と突き合わせて確認するための手順。
実装仕様は `仕様書_セール価格設定リスト_データ仕様.md` §11、データ仕様は同 §2〜§10 を参照。

**この手順で確かめたいこと**

1. 出力機能が仕様どおり動くか（属性・実績が旧システムと一致するか）
2. **テンプレートのフィルタ範囲が直っているか**（仕様書 §12-2 の未解決 1 件目）

## 5. STEP3｜出力を実行する

作成したレコードの**詳細画面でボタンを押下**する。

処理の流れ（§11-4）:

```
商品マスタ（販売中の商品）を起点に
salegoods / 在庫分析 / 売上・注文 から条件の合うデータを突合
  ↓
ブランド（親カテゴリ）ごとに Excel を作成
  ├ Google ドライブのテンプレートからブランドファイルにコピー
  └ 集めたレコードを記載
  ↓
セール価格設定アプリ（k/60）に登録
  1ブランド 1レコード 1添付ファイル ＋ メーカーマスタからの宛先
```

実行後、[セール価格設定 k/60](https://zrqf50naoiwx.cybozu.com/k/60/) に
**対象メーカーのブランド数だけレコードができている**ことを確認する。

## 6. STEP4｜出力ファイルの目視確認 ★最重要

k/60 の添付ファイルをダウンロードして開き、**次の4点を見る。**

### ① フィルタ範囲（これが今回の主目的）

Excel で `数式 > 名前の管理`、または名前ボックスに `_FilterDatabase` と入力して範囲を確認する。

| | 判定 |
|---|---|
| `A2:W<データ最終行>` に近い形 | **直っている** |
| `A2:AG3` 固定 | **直っていない。**従来の不具合がそのまま |
| `A2:W2000`（データが2,000行未満でもテンプレのまま） | テンプレの範囲がそのまま来ている。実害の有無を判断する |

**実測値をメモに残す。**「たぶん大丈夫」で済ませない。

### ② W列より右にフィルタの ▾ が出ていないか

テンプレ作り直し後の画面で、X〜Z あたりにも ▾ が見えていた。空列なので実害は無いが、
出ているかどうかは記録する。

### ③ 行構成が突合スクリプトの前提と合っているか

```
1行目 = グループ見出し
2行目 = 項目名
3行目 = データ開始
```

### ④ 列が A〜W の 23 列か

`A:親カテゴリ` 〜 `W:直近30日お気に入り登録数`。列がずれていると突合が全滅する。

## 7. STEP5｜突合スクリプトを実行する

出力された xlsx を**1つのフォルダにまとめる。**ファイル名の**先頭はメーカーNo.**
（例: `2_株式会社 スタンレーインターナショナル様_セール価格設定_….xlsx`）。
ゼロ埋めの有無はどちらでもよい。

```bash
cd エクセル開発\検証スクリプト

python キントーン突合.py ^
  --kintone "<kintone 出力を置いたフォルダ>" ^
  --旧 "...\セール情報設定リスト202608089～202608219\送信" ^
  --メーカー 2
```

- `--メーカー` はゼロ埋め不要（`2` でよい）
- 結果は `--kintone` のフォルダに `YYMMDD_kintone_旧システム_突合結果.xlsx` として出る
- 旧システム側は**1メーカーが複数ファイルに分かれていても自動でまとめて読む**

## 8. STEP6｜結果の読み方

### コンソール出力

```
メーカー  2 株式会社 スタンレーインターナショナル
    キントーン   221行（在庫あり n） / 旧   221行 / 共通 221 / kのみ 0 / 旧のみ 0
    属性の不一致 0 件 / 実績の不一致 n 件
```

### 突合結果 xlsx（6シート）

| シート | 内容 |
|---|---|
| `1_サマリ` | 件数と一致状況 |
| `2_項目マッピング` | キントーン23列と旧45列の対応 |
| `3_属性の不一致` | 明細 |
| `4_実績の不一致` | 明細 |
| `5_キントーンのみ` | キントーンにしか無い品番 |
| `6_旧システムのみ` | 旧にしか無い品番 |

### 判定の目安

| 見るところ | 期待 | ずれたときに疑うもの |
|---|---|---|
| **属性の不一致（10項目）** | **0 件** | **移行ロジックそのもの。**実装側の問題として差し戻す |
| **実績の不一致（9項目）** | 少ないほどよい | 抽出条件（どの列を採るか、集計期間）。2026-09-01 時点では全体で1,163件出ていた |
| 行数（共通 / kのみ / 旧のみ） | 一致 | 抽出条件。アーカイブ商品の除外（§12-1）ができているか |
| `販売開始日` の不一致 | **無視してよい** | 実行日に依存する項目。突合対象から外す判断済み（§12-1） |
